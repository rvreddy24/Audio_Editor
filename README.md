# 🚀 rajvarshith.com - Unified Web Workstation Suite

**rajvarshith.com** is a high-performance, privacy-first web workstation suite combining multimedia production, document editing, and computational tools directly inside your browser.

Designed for speed, precision, and complete privacy: heavy document, image, and calculation tasks run 100% client-side, while intensive audio and video operations are powered by a dedicated high-throughput **Node.js Express + Native FFmpeg 8.1** engine.

## ✨ Features by Workstation

### 1. 📄 PDF & Document Toolkit (25+ Tools)

- **Interactive Canvas Editor & Signer**:
  - Type text anywhere on canvas with custom fonts, colors, and sizes.
  - Draw freehand signatures or type cursive signatures with instant transparent background rendering.
  - Whiteout, redaction blackout, highlighter, and geometric shapes (rectangles, circles, lines, arrows).
  - Multi-page navigation, zoom controls, and client-side high-resolution PDF burning.
- **Organization & Layout**:
  - **Merge PDF**: Combine multiple PDFs into a single ordered document.
  - **Split PDF**: Extract specific page ranges or burst into individual single-page documents.
  - **Organize & Rotate**: Reorder, delete, duplicate, and rotate individual pages.
- **Optimization**:
  - **Compress PDF**: Triple-tier compression (Extreme, Recommended, Less) to minimize file size while preserving legibility.
  - **Repair & Flatten**: Rebuild damaged PDF xref tables and flatten interactive form fields into static graphics.
- **Universal Document Conversion**:
  - Convert between PDF and `Word (DOCX)`, `Excel (XLSX)`, `PowerPoint (PPTX)`, `JPG/PNG`, `HTML`, and archival `PDF/A`.
- **Security & Watermarking**:
  - Encrypt with AES-256 password protection and unlock encrypted documents.
  - Stamp customizable text or image watermarks with opacity and angle controls.
  - Add standardized page numbers with custom position (top/bottom, left/center/right) and numbering formats.
- **Optical Character Recognition (OCR)**:
  - Extract editable text from scanned documents and image-based PDFs.

### 3. 🎵 Audio Studio & DSP Mastering

- **Universal Format Converter & Bitrate Scaler**:
  - Supported formats: `MP3`, `WAV` (Lossless PCM), `FLAC` (Audiophile Lossless), `AAC`, `M4A` (Apple), `OGG` (Vorbis), `OPUS` (Ultra-low latency), `AIFF`, `WMA`.
  - Scalable bitrates from `32 kbps` to `320 kbps` with instant output file size estimator.
  - Configurable sample rates (22.05 kHz up to 96 kHz Hi-Res) and channel configurations (Stereo / Mono).
- **Interactive Waveform Cutter**:
  - Visual waveform rendering via Web Audio API with 1x to 5x zoom and millisecond timecode inputs.
  - **Dual Mode Trimming**: Keep Selection (isolate clip) or Cut & Splice (remove unwanted middle sections without clicks or pops).
  - Adjustable linear envelope Fade-In and Fade-Out (0 to 10s).
- **Video to Audio Extractor**:
  - Extract high-fidelity audio tracks from `MP4`, `MKV`, `MOV`, `WebM`, or `AVI` videos.
- **DSP Mastering & Effects**:
  - **Tempo & Pitch**: 0.25x to 2.5x tempo stretching and -12 to +12 semitone key transposition.
  - **Volume & Normalization**: +10 dB clean gain booster and broadcast -14 LUFS loudness normalization (YouTube/Spotify standard).
  - **Equalization**: Bass Boost, Treble Brightness, Vocal Clarity, Lo-Fi Muffle, and Vintage Radio.
  - **Special FX**: 360° Binaural 8D Spatial Audio, Audio Reversal, and Vocal Remover / Karaoke isolation.
- **Multi-Track Joiner & Sequencer**:
  - Chain multiple tracks in sequence with drag-and-drop reordering and seamless DJ crossfade blending.
- **ID3 Tag Editor & Voice Recorder**:
  - View and edit embedded metadata (Title, Artist, Album, Year, Genre).
  - In-browser microphone recorder with live frequency spectrum visualizer.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or later)
- [FFmpeg](https://ffmpeg.org/) (installed and accessible on system `PATH`)

### Installation & Launch

1. Clone or navigate to the repository directory:
   ```bash
   cd "d:/Audio Editor"
   ```

2. Install dependencies:
   ```bash
   npm install
   npm run build --prefix client
   ```

3. Start both backend server and client:
   ```bash
   npm start
   ```

4. Open your browser:
   - **Production Suite**: `http://localhost:5000`
   - **Vite Dev Server (with HMR)**: `http://localhost:5173`
